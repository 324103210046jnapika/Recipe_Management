## ▶️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/324103210046jnapika/Recipe_Management.git

2. Go to the project folder:

cd Recipe_Management/Projects


3. Install dependencies:

pip install flask


4. Run the application:

python app.py


5. Open in browser:

http://127.0.0.1:5000/
